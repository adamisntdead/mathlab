Initial runnable research-lab release.

Highlights:
- GPT-6 Astra Responses API workers with `max` reasoning support.
- OpenAI native local-shell tool protocol executed in the user's VM.
- Persistent SQLite blackboard and crash-resumable project state.
- Parallel research islands, director scheduling, seminars, targeted messages.
- Code-enforced evidence ladder and fresh-context verification pipeline.
- Live Textual TUI with streamed model and local shell output.
- Human steering commands from the TUI.
- Budget/token accounting.
- RA framework-engineer agent with capability requests and hot-loadable project extensions.
- Markdown/text/TeX and PDF research handoff ingestion.
- Headless mode and environment diagnostics.
